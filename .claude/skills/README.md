# Skills do projeto `foto-manager-app`

Skill de **processo deste projeto**. Uma pasta por skill, com `SKILL.md` dentro:

```
.claude/skills/<nome-da-skill>/SKILL.md
```

Skill genérica de mercado fica global em `~/.claude/skills`. Skill que vale para mais de um
projeto do workspace vai em `../.claude/skills/`. Ver `AGENTS.md` da raiz do workspace.
