# Foto Manager — App (Electron)

Aplicativo desktop de gestão de fotos de produtos. Continua funcionando em paralelo à Central.

- **Repositório:** https://github.com/tecnologia-eita/foto-manager-app
- **Stack:** Electron + Vite
- **Scripts:** `dev` · `vite` · `build` · `package` · `make` · `publish-release`
- **Publicação:** ver `PUBLISH.md` (release via GitHub — `publish-github.js`,
  `publish-release.js`)

## Relação com a Central

Fala com a `foto-manager-api` (ver `../foto-manager-api/AGENTS.md`), a mesma API que o módulo
`fotos` da Central usa para escrever. Os dois clientes coexistem.
